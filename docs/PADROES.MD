O projeto deve incluir todos os metodos a seguir:]

1) Factory Method Utilizado quando subclasses ou implementações especializadas devem decidir qual objeto concreto será criado.

2) Abstract Factory Utilizado para criar famílias de objetos relacionados que precisam trabalhar de maneira compatível entre si.

3) Builder Utilizado para construir objetos complexos passo a passo, especialmente quando existem diversas opções ou partes opcionais.

4) Prototype Utilizado quando novos objetos podem ser criados a partir da clonagem de objetos existentes.

5) Singleton Utilizado quando determinado recurso precisa possuir uma única instância compartilhada por todo o sistema.
